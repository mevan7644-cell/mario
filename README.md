# Mario 2D Game

A lightweight Mario-style 2D platformer built with plain HTML5 Canvas + JavaScript.

## Run locally

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Controls

- Move left/right: `←` / `→` or `A` / `D`
- Jump: `Space`, `W`, or `↑`
- Restart after win/lose: `R` or `Enter`

## Goal

Collect coins, avoid enemies, and reach the flag at the end of the level.
